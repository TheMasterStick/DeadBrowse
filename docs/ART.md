# Original game artwork

`public/art/city-atlas.webp` is original AI-generated artwork created for DeadBrowse on 28 September 2026 with the built-in image generation tool. The supplied Travian and Torn screenshots informed the general interface direction; no screenshot assets were copied into the game.

The generated atlas contains nine abandoned contemporary city locations in a hand-painted isometric strategy-game style: row houses, clinic, industrial works, park, refuge, market, checkpoint, water utility, and apartments. The palette uses muted greens, warm stone, weathered roofs, and soft daylight. The generation brief requested consistent isometric scale, no text, and a three-by-three atlas. The PNG output was converted to WebP for delivery; CSS selects each tile. The source is not a licensed Travian, Torn, or Urban Dead asset.
